# Sign-in

better-auth runs in the API Worker (`apps/api/src/auth.ts`) on the project's D1 database and serves `/api/auth/*` itself. To protect endpoints, put them in a group of the contract with `.middleware(Authentication)` (`packages/domain/src/account.ts`) and read `CurrentUser` in the handler; a handler test provides a stand-in for `Authentication`, as `apps/api/test/api.test.ts` does. Never take the user's id from a request body. A better-auth plugin that adds tables needs no file in `migrations/`: Alchemy migrates better-auth's tables when the stack starts or deploys. The website holds the password in the Model as a `Redacted` value, so the DevTools print a placeholder for it. better-auth's options are its own: look them up at https://better-auth.com/docs, and Alchemy's side of it at https://alchemy.run/better-auth.
